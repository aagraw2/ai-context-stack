# Fundamentals Quick Reference

## SOLID
| Principle | One-liner |
|-----------|-----------|
| S - Single Responsibility | One reason to change |
| O - Open/Closed | Extend, don't modify |
| L - Liskov Substitution | Subtypes are substitutable |
| I - Interface Segregation | Small, specific interfaces |
| D - Dependency Inversion | Depend on abstractions |

## Clean Code
| Principle | One-liner |
|-----------|-----------|
| DRY | Single source of truth |
| KISS | Simplest solution that works |
| YAGNI | Build for today, not tomorrow |
| Composition > Inheritance | Has-a over is-a |
| Fail Fast | Error early, error clearly |
| Law of Demeter | Only talk to friends |

## Error Handling
- Exceptions for exceptional cases
- Specific exception types with context
- Result types for expected failures
- Validate at boundaries
- Never swallow exceptions
